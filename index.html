每日財經影片 · 自動化工具

Daily-finance-uploader

將公開財經市場資料整理成每日摘要和 MP4 影片，再透過 GitHub Actions 將成品上傳至專案操作者指定的 Google Drive 資料夾。

隱私權政策專案原始碼

如何使用

  1. 專案操作者在自己的 Google 帳戶授權工具，並設定用於接收影片的 Drive 資料夾。
  2. GitHub Actions 依排程整理資料和產生影片。
  3. 工具上傳影片；如果它可存取的目的資料夾中已有同名檔案，就更新該檔。

本站僅提供工具說明，不要求訪客登入 Google，也不是這項工具的登入或授權入口。Drive 成品是否可共用，由檔案或資料夾原本的權限決定。
