隱私權政策

適用於本公開說明網站及 Daily-finance-uploader 的 Google Drive 上傳功能。

存取哪些 Google 資料

工具使用 Google Drive 的 drive.file 權限，只能建立新檔，或存取這項工具已獲授權的特定檔案。它在設定的目的資料夾中查找可存取的同名影片，並使用檔名、檔案識別碼、連結、大小和修改時間處理上傳結果。不讀取 Gmail、聯絡人或整個 Drive，也不使用 Google 帳戶資料產生財經內容。

用途與儲存

Drive 存取只用於把產生的 MP4 新增或更新到指定資料夾，以及記錄上傳結果。成品留在該 Drive 資料夾，直到有權限的人刪除。GitHub Actions 使用專案的 Secrets 儲存 OAuth 憑證；執行記錄與暫存的執行成品可能包含上傳回應中的檔案資訊與連結。依現行設定，若 GitHub 執行成品成功保存，其保留期為 14 天；執行記錄依 GitHub 專案設定保留。

分享與網站訪問

此工具使用 Google Drive 儲存成品、使用 GitHub 執行自動化及託管本說明頁。工具不出售 Google 使用者資料、不用於廣告，也不會變更 Drive 共用權限。Drive 成品依原有共用設定開放；GitHub 執行記錄或成品內的檔案資訊與連結，則依該 GitHub 專案的可見性與存取規則提供。說明網站沒有登入表單、追蹤程式或分析工具；託管服務仍可能依自身政策處理一般連線資訊。

撤銷授權及刪除

可在 Google 帳戶的第三方連線 移除 Daily-finance-uploader，停止日後的 Drive 存取。撤銷不會自動刪除已上傳的影片；可在 Drive 自行刪除。GitHub 的憑證、上傳記錄或暫存成品可由有權限的專案管理者移除。

聯絡

隱私問題請使用 Google 授權畫面所列的應用程式支援信箱，或在 GitHub 專案 提出一般問題。請勿在公開議題張貼個人資料、私人檔案連結或憑證。
